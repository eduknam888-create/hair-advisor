# Hair Advisor

Upload a photo of your head/hair and get:

- Hair basics (estimated type, shade, density, undertone)
- A daily/weekly routine
- Products to buy
- Haircut options
- A plain-text brief you can hand to your barber
- General care tips

## Two modes

- **Demo (default):** fully client-side. Samples hair/skin colors and texture variance from the image and maps them to a rule-based recommendation. Photos never leave your browser.
- **Live:** paste an Anthropic API key in the "Use real AI" section. The image is sent to Claude vision and the report is generated by the model. Your key stays only in that browser tab.

Live mode calls `https://api.anthropic.com/v1/messages` directly from the browser using the `anthropic-dangerous-direct-browser-access` header. That is the intended path for personal-use static sites; do not paste a key you also use in production.

Not a substitute for a trichologist or a real barber consultation. The heuristic engine is a rough demo — for a serious analysis, use Live mode.
